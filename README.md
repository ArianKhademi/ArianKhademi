## Selected work

### [Rigforge](https://github.com/ArianKhademi/rigforge)

Turn a video of someone moving into a previewable, exportable 3D motion asset. Go APIs, resumable uploads, Python workers, and a React interface, with job retries and crash recovery.

**Built with:** Go · Python · React · PostgreSQL · Redis · Kubernetes

### [jwkit](https://github.com/ArianKhademi/jwkit)

JWT verification for Go and TypeScript, with matching validation behavior, key-rotation-aware caching, and middleware for Gin and Express. Cross-language conformance, fuzzing, and property tests check the edge cases.

**Built with:** Go · TypeScript · JWT/JWKS

### [Splatbox](https://github.com/ArianKhademi/splatbox)

A browser-based library for 3D assets, animation clips, and Gaussian splats. Includes synchronized video and motion playback, Blender-powered conversion, and asynchronous turntable previews.

**Built with:** React · TypeScript · Three.js · Node.js · Blender
